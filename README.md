Numerical Methods Website

An interactive educational website designed to help students learn, practice, and solve numerical methods.

Features:
    Learn numerical methods through educational content
    Solve numerical problems interactively
    View calculation steps, tables, and graphs
    Test knowledge using quizzes
    Explore error analysis and convergence

Technologies Used:
Python
Streamlit
NumPy
Pandas
Matplotlib
SymPy

Project Structure:
numerical_methods_site/
├── app.py
├── requirements.txt
├── assets/
├── components/
├── pages/
├── utilities/
└── .streamlit/

Installation
Clone the repository and install the required libraries:

    pip install -r requirements.txt

Run the application:

    streamlit run app.py
